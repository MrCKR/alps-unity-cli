# HDRP Tools

The extension contributes independent tools for the active High Definition Render Pipeline asset.

| Tool | Description |
| --- | --- |
| `hdrp.volume-list` | List scene-session volumes. |
| `hdrp.volume-create` | Create a scene-session volume. |
| `hdrp.volume-info` | Read one scene-session volume. |
| `hdrp.volume-add-effect` | Add one effect to an in-memory profile. |
| `hdrp.volume-set` | Set one effect parameter and return its verified typed serialized readback. |
| `hdrp.settings-get` | Read active pipeline asset settings. |
| `hdrp.settings-set` | Set one active pipeline asset setting. |

The project must install `com.unity.render-pipelines.high-definition` and select an active `HDRenderPipelineAsset`.
